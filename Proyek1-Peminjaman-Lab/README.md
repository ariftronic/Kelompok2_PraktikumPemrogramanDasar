# Proyek 1: Sistem Peminjaman Peralatan Lab

Proyek ini merupakan sistem manajemen peminjaman peralatan laboratorium untuk pemenuhan tugas Proyek 1 Praktikum Pemrograman Dasar - Kelompok 2.

## Struktur Direktori
- `main.py`: Titik masuk utama aplikasi.
- `modules/`: Modul fungsionalitas (mahasiswa, peralatan, sistem lab, statistik, transaksi).
- `tests/`: Pengujian unit test untuk masing-masing modul.
- `dokumentasi/`: Dokumentasi UML (individu & final kelompok), code review, keputusan desain, dan pengujian.
